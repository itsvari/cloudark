## A familiar journey

RidgeBus is an independent project for checking NUS shuttle arrivals through native applications. The work covers Android and Wear OS, alongside SwiftUI applications for Apple devices.

Local favourites, offline stop lists and maps are part of the experience. Widgets and companion devices explore how much of the journey can be handled without opening a full application.

## Current state

The Android application is at alpha stage. Apple and watch hardware validation is still pending, so the different targets are work in progress rather than a claim of a finished release across every platform.

The source is private. This page is a high-level overview of the project.
