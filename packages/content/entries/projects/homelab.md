## Infrastructure at home

I designed and manage a home network built around two custom-built TrueNAS systems and a Raspberry Pi.

It provides shared storage, redundant automated backups for family devices, a media server, a game server and ad-blocking DNS.

## Reliability has a user

A home network makes reliability concrete. The people using the storage and backups need those services to work without thinking about the machines behind them.

This is the ongoing infrastructure project described in my CV. It sits alongside the web and AI work as another way to learn by building something people actually use.
